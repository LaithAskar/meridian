### Blocker A — yfinance network access (blocks 3.1)

The cloud execution environment's outbound allowlist blocks `query1.finance.yahoo.com` and related
Yahoo Finance hosts. Every `yf.download()` call returns HTTP 403: Host not in allowlist.

The code is correct and fully tested with monkeypatched data. `run_quant.py` is ready to run.
Only the live download step is blocked.

**Two paths to unblock (documented in detail in journal/2026-05-15-pm9.md):**

1. **Enable network access** (fastest): Add Yahoo Finance hosts to the cloud environment's outbound
   allowlist. Once enabled, `python -m backtest.run_quant` runs the full 2010-2024 backtest
   (~5-10 min cold) and writes `backtest/results/quant/{equity_curve,trades,spy_curve}.csv` +
   `metrics.json`.

2. **Pre-download and commit parquet cache** (self-contained, recommended): Run on a machine with
   unrestricted network:
   ```python
   from datetime import date
   from backtest.data import fetch_bars
   from backtest.universe import UNIVERSE_2010
   fetch_bars(UNIVERSE_2010, date(2010, 1, 1), date(2024, 12, 31))
   fetch_bars(['SPY', '^VIX'], date(2010, 1, 1), date(2024, 12, 31))
   ```
   Then `git add data/cache/ && git push`. The next routine run will find the parquet files via
   `_cache_covers`, skip all downloads, run the engine, and write results. Estimated parquet size:
   ~180 MB for 100 tickers × 14 years of daily OHLCV bars.
