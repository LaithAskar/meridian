## Explanation

### Why the blocker is real

The live bot uses `YFinanceSource.fetch_headlines()` which calls `yf.Ticker(ticker).news`. This endpoint returns the ~10-40 most recent articles for a ticker — it has no `start`/`end` date parameters and no historical pagination. There is no way to reconstruct "what news existed on 2017-03-14 for AAPL" via yfinance. All other sources in `backend/trading/sources/` (Finviz, Reddit, Twitter, StockTwits) are similarly real-time scrapers with no historical archive. The backtester's event loop calls `strategy.on_bar(ts, bars, portfolio)` at each historical timestamp and expects the strategy to emit signals as if it were live at that date. A VADER or FinBERT strategy that reads *today's* headlines while looping over a 2017 bar date would produce a pure look-ahead bias artifact — a meaningless, potentially spectacular backtest number that would embarrass you in an interview.

### Options evaluated

---

#### Option A — Polygon.io News API (paid)

- **What it is:** Polygon offers a ticker-tagged news endpoint (`/v2/reference/news`) with full historical coverage from ~2010. Articles include publication timestamps, tickers, and full text/summary. This is the same vendor quality used by institutional quants.
- **Cost:** Stocks Starter plan is ~$79/month; unlimited history requires the Developer plan at ~$199/month. A one-time 14-year pull for 100 tickers would likely cost 1-2 months of access (the data can be cached to parquet once fetched).
- **Effort:** ~1 day. Write a fetcher analogous to `data.py`'s `fetch_bars`, cache to `data/cache/news/{symbol}.parquet`. The sentiment wrapper then reads from that cache, no live calls during backtest.
- **Data quality:** High. Clean timestamps, deduplicated, tagged by ticker. Defensible in an interview as "institutional-grade data."
- **Gotcha:** Polygon's free tier caps at 5 API calls/minute and has no historical news access. Requires a paid subscription for any historical query. Their `PGNX` (pharmaceutical) or very small-cap articles may be thin before 2015.
- **Verdict:** Best quality if budget allows. Likely ~$79-200 for a one-time pull.

---

#### Option B — GDELT Project (free, messy)

- **What it is:** GDELT (Global Database of Events, Language, and Tone) is a free dataset of global news articles, updated every 15 minutes. The GKG v2 (`gkg.csv`) files contain company/organization mentions, sentiment scores (`AvgTone` in [-100,+100]), and timestamps back to 2013 (reliable) or 2011 (patchy).
- **Cost:** $0. Files are downloadable directly from `http://data.gdeltproject.org/gkg/`.
- **Effort:** 3-4 days minimum.
  1. Download daily GKG v2 files for 2013-2024 (raw size: ~4 TB uncompressed, ~400 GB gzipped over 11 years). Even compressed, this is impractical without BigQuery.
  2. Filter rows where the `Organizations` or `Persons` field contains the company name (not ticker symbol — GDELT uses full names, not tickers). Matching "Apple Inc." → AAPL, "JPMorgan Chase" → JPM requires a fuzzy entity map.
  3. Aggregate per-company per-day AvgTone into a signal. GDELT's AvgTone is a general document tone, not a financial-domain sentiment — it's less accurate than VADER for equity moves.
  4. BigQuery free tier gives 1 TB/month of query processing — enough for targeted queries but requires a Google account and BigQuery setup.
- **Data quality:** Noisy. GDELT AvgTone is not trained on financial text. The entity-to-ticker mapping is the hardest part and introduces false positives ("apple" in agricultural news → incorrectly attributed to AAPL, though GDELT's entity extraction is better than naive string matching). Coverage before 2013 is thin.
- **Verdict:** Viable for a 2013-2024 window if Laith is willing to invest the engineering time. The GDELT AvgTone can stand in for VADER compound score if you document the substitution. Interview-risky if someone asks "why didn't you use financial-domain sentiment?" — answer is "it was the only free historical source."

#### Option D — Subset window with a commercial-but-affordable source

- **What it is:** Use a cheaper or free-tier news API for a shorter window, e.g., 2022-2024 (2-3 years).
  - **Alpha Vantage News Sentiment API:** Free tier gives 25 requests/day (impractical for 100 tickers × 2 years). Premium is $50/month.
  - **Benzinga API:** Historical news, ~$99/month.
  - **yfinance.Ticker.news:** Returns only the last ~30-90 days. No historical lookback even for a 2-year window. **Not usable for any historical backtest.**
- **Problem:** Mixing a 2010-2024 quant backtest with a 2022-2024 sentiment backtest makes the comparison table look odd. You'd need to clearly label the different windows, which reduces the narrative clarity.
- **Verdict:** Intermediate option if Laith wants sentiment numbers but doesn't want to pay for Polygon. Not recommended — the window mismatch weakens the comparison story.

---

#### Option E — Use SEC EDGAR filings as sentiment proxy

- **What it is:** Quarterly 10-Q and annual 10-K filings are available free via EDGAR from 1993. Run VADER/FinBERT on the MD&A section. 4 data points per year per company.
- **Problem:** 4 signals per year is too coarse for a daily backtest. The effective holding period would be quarterly, which is not what VADER/FinBERT were designed for. The signal would be so stale by the time it's tradeable that any edge would disappear in the 5 bps round-trip cost.
- **Verdict:** Not viable for this backtester's design.
